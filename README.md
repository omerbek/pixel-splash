# Pixel Splash / Piksel parçacıkları

## Türkçe

[Canlı aracı aç](https://omerbek.github.io/pixel-splash/).

Izgaraya oturan deterministik bir su sıçraması oluştur.

## Çalıştırma

`index.html` dosyasını bir tarayıcıda aç. Oynat düğmesini ve zaman çizelgesini kullanarak sekiz saniyelik sahneyi incele. HTML ve Canvas 2D ile çevrimdışı çalışır.


## Sahne ayarları

- Parçacık sayısı
- Piksel boyutu
- Döngü süresi (s)

Sekiz saniyelik zaman çizelgesinden bir kare seçip **PNG indir** ile 720 × 405 piksel dışa aktarabilirsin.

## English

Tune particle count, pixel size and loop duration.

Open [the live tool](https://omerbek.github.io/pixel-splash/) or open `index.html` in a browser. Switch between Turkish and English in the page header. Use the timeline to select a frame and **Download PNG** to save it at 720 × 405 pixels.
